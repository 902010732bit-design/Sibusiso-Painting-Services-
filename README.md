# Sibusiso Painting website

A responsive static website designed for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `sibusiso-painting`.
2. Upload **all files and folders** in this project. Keep `index.html` in the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.
